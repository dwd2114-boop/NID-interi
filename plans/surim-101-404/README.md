# 수림아파트 101동 404호 — 리모델링 평면 (NID종합공사 상세 견적 반영)

공급 90㎡(27평) / 전용 72㎡(모델 벽중심 기준 72.04㎡) · 천장고 2,300mm · 견적일 2026.09.26

| 파일 | 내용 |
|---|---|
| `surim_101-404.rb` | **SketchUp 모델 생성 스크립트** (textures 폴더와 함께 사용) |
| `render_top.jpg` | 실사 탑뷰 평면 렌더 (기존 가구 제거, 견적 품목만 배치) |
| `render_3d_A.jpg`, `render_3d_B.jpg` | 버드아이 투시 렌더 (안방·거실 방향 / 주방·현관 방향) |
| `plan_2d.png`, `plan_2d.svg` | 치수 + 견적 No. 번호가 표기된 2D 평면도 |
| `layout.json` | 평면·품목 좌표 데이터 (위 결과물 공통 소스) |
| `src/` | 생성 스크립트 (layout.py → layout.json → .rb / 렌더 / 2D) |

## SketchUp에서 여는 법
1. `surim_101-404.rb` 와 `textures/` 폴더를 같은 위치에 둡니다.
2. SketchUp 새 파일 → **창 > Ruby 콘솔** → `load 'C:/경로/surim_101-404.rb'`
3. 장면 탭 `01 평면도(탑뷰)` / `02 투시도` 가 생성됩니다. 필요하면 `.skp` 로 저장하세요.
   그룹 이름 앞 `[번호]` = 상세 견적내역서 No.

## 가정·확인 필요 사항
- 평면 치수는 기존 평면 이미지 비율과 전용 72㎡에 맞춰 추정했습니다. 실측 후 `src/layout.py` 좌표만 바꾸면 전체가 다시 생성됩니다.
- 작은방 = 좌하단 방(창고 연결). 작은방 발코니 창은 "작은방 제외"에 따라 기존 샤시로 표시했습니다.
- 공용욕실 욕조는 견적에 없어 해바라기 샤워(방수·타일·도기 포함)로 표현했습니다. 샤워부스 유리는 견적에 없어 넣지 않았습니다.
- 냉장고·침대·소파 등 견적 외 가구는 넣지 않았습니다.
